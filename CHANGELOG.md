# Changelog

All notable changes to this project are documented here.

## [1.2026.1.2] - 2026-07-24

### Initial public release

- Added source and target Dataverse connection support.
- Added Word and Excel document-template retrieval.
- Added `Identical`, `Different`, `Source Only`, `Target Only`, and `Duplicate` classifications.
- Added normalized Office-package comparison for environment-specific entity type codes.
- Added separate **Copy Missing** and **Update Existing** operations.
- Added same-environment, duplicate, invalid-selection, and newer-target safeguards.
- Added dry-run previews and stronger update confirmations.
- Added Draft and Activated status preservation.
- Added post-write retrieval and verification of content, metadata, status, table, type, and language.
- Added automatic comparison refresh after successful transfers.
- Added search, filters, detailed row inspection, CSV evidence export, and activity logging.
- Added Copy Log and Clear Log.
- Added accessible high-contrast row selection.
- Added raw and normalized hash labels and explanations.
- Added embedded 32 × 32 and 80 × 80 tool icons.
