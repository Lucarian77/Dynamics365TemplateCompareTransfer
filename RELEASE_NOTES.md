# Release notes: 1.2026.1.2

This is the first public release of **Dynamics 365 Template Compare & Transfer**.

The tool compares Word and Excel document templates between two Dataverse environments and supports controlled source-to-target transfers. It distinguishes missing, different, identical, target-only, and duplicate records and blocks ambiguous or invalid writes.

Key release capabilities:

- Separate copy and update operations
- Dry-run previews
- Newer-target warnings
- Same-environment protection
- Draft and Activated status preservation
- Post-write content and metadata verification
- Automatic comparison refresh
- Raw and normalized SHA-256 diagnostics
- CSV evidence export
- Detailed row view and visible activity logging
- Accessible high-contrast selection

All planned functional, safety, cancellation, search, logging, Word-template, Excel-template, and CSV-export tests passed before this release.
